# Disasteronomy — Project Context

Reference guide to the project structure and current gameplay flow.

## 1. Overview

- **Game:** Disasteronomy, a co-op 2D pixel-art space-disaster game created for a hackathon.
- **Engine:** Godot 4.7.2 Mono/C#, .NET 8, Forward Plus renderer.
- **Code:** C# with GDScript for the high-level networking autoload and LAN menu.
- **Platform:** Windows desktop.

### Current scene flow

```text
Intro.tscn → MainMenu.tscn → MatchSetup.tscn
  → Cutscene1 → Cutscene2 → Cutscene3
  → Lobby/lobby.tscn → Cutscenes/IntroLvl1.tscn → Phase1/Phase1.tscn
  → Level 1 report → Cutscenes/EdLvl1.tscn → GameEnd.tscn → MainMenu.tscn
```

The campaign ends after Level 1. The Level 2 prototype is still in the repository, but it is not
reachable through the current campaign flow.

### Autoloads

| Autoload | File | Purpose |
|---|---|---|
| `HighLevelNetworkHandler` | `Scripts/high_level_network_handler.gd` | ENet multiplayer, LAN discovery, room codes, player names and readiness |
| `SceneTransitions` | `Scripts/Core/SceneTransitions.cs` | Fade transitions between scenes |
| `Global` | `Scripts/Core/Global.cs` | Video/audio settings, input remapping, saves and mission progress |
| `Music` | `Scripts/Core/MusicManager.cs` | Menu music and volume control |

### Build and run

- Build from the project root with `dotnet build disasteronomy.csproj` or Godot's **Project → Tools → C# → Build**.
- Main scene: `res://Scenes/Intro.tscn`.
- There is no automated test suite.

## 9. Implementation notes

- Level 1 grip, tool and CPS positions are specified in image pixels by `Phase1Manager` and converted to world coordinates.
- Player replicas use the peer ID as their node name and multiplayer authority.
- The lobby Terminal is host-only. Activating it starts a synchronized countdown and transitions the match to Level 1.
- Level 1 records its result in `Global`. The result screen leads to `EdLvl1`, which automatically advances to `GameEnd`.
- The final screen's button uses `SceneTransitions.GoToMainMenu()` when available.
- The input map uses English action names such as `move_left`, `move_right`, `jump`, `interact` and `voice_chat`.
- Godot-generated `.godot/` cache files are excluded from project source changes.
